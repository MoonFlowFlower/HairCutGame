# B2-only scanned textile inputs

- Caban: https://polyhaven.com/a/caban
- Wool Boucle: https://polyhaven.com/a/wool_boucle
- License: CC0, https://polyhaven.com/license
- Photography: colormass. Processing: Rico Cilliers.
- Retrieved 2026-10-01 through the public Poly Haven files API.

The original 1K JPG displacement and OpenGL normal maps are unmodified. Only their sampling, scale and influence are changed in the B2 shaders. No original diffuse color/character design is copied. `downloads.json` records URLs, checked upstream MD5 and local SHA256; `source-metadata.json` preserves API responses.
