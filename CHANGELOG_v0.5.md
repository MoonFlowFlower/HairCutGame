# v0.5 Delta Changelog

This pack does not represent implemented code. It updates product/technical requirements for the next Codex pass.

New direction:
- low-poly semi-soft readable hair material,
- material states visually and physically distinct,
- expanded tool grammar beyond add/remove,
- natural tool constraints instead of arbitrary nerfs,
- sculpting consequence previews,
- personal diegetic three-view reference board,
- shared miniature target model,
- optional rather than dominant spatial ghost,
- physical target props prepared/ordered and placed during construction,
- validation operates on those exact existing props,
- scoring expands from shape toward shape + material state + function.
