## Decisions
- Pure C# simulation and tests share source; engine layer supplies movement, rendering, inputs and ENet.
- Authoritative quantized density lattice (0.14 world-unit resolution; 35 × 31 × 27 samples). Extract a closed faceted boundary mesh locally; never render the cells or old control columns.

- One pure C# simulation serves offline and host. Remote peers send movement/look/buttons; host moves collision bodies, resolves range/occlusion and applies effects. It never accepts client hit IDs, state deltas or scores.
- Reconciliation sends compressed logical snapshots at 5 Hz, input capped at 20 Hz, local movement prediction with host correction. No per-segment RPCs. Prototype favors simple reliable state over production delta encoding.
- Target volumes are composable boxes/cylinders/unions. Score uses sample precision/coverage harmonic mean, weighted 70/20/10 minus source penalties.
- Goal/tool definitions are inspectable C# records in src/Core/Definitions.cs; content changes do not require rewriting the match loop.
- Validation uses unlocked copies of submitted geometry so physical checks may deform the test while gameplay submission remains immutable.
- Mirrors use an isolated portrait viewport rather than planar reflections. The caption states this explicitly.
- Ragdoll is a single tumbling collision body, not a jointed anatomical skeleton. Hair follows its location during recovery.
- Eggs, water, animals and vehicles are deterministic collision/support proxies. No fluid simulation or animal AI; checks run against actual logical hair and stiffness.
- Wigs/bundles use coarse gravity and floor/wall bounds. Tools settle immediately when dropped. No large collection of per-patch physics bodies.
- Highlight playback is visual; dedicated replay avatars prevent historical transforms from changing live gameplay state.
- Locked validation uses a labeled spectator camera to show the customer's test. Normal gameplay remains first-person. Playback records customer tumble facts as well as hair/player/tool states and frames the host-selected event location.
- Fire attribution has its own source field, so a helper trimming burning hair is not charged for the original ignition.
