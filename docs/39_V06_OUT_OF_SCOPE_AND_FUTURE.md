## If B passes — likely next hypotheses

### Microphone / real laughter

Test first with Wizard-of-Oz behavior:

- developer observes the group’s normal voice channel;
- laughter/shout manually triggers a directional attention event;
- observe whether players spontaneously shush each other or weaponize sound.

Only then justify real microphone integration.

### Early call / greed

If teams regularly finish early and wait, test a separate B2 rule:

- anyone can call the helicopter early;
- earlier successful landing pays more;
- this creates impatient vs perfectionist tension.

Do not mix this into the first A/B result.

### Physical mission props

Return to bird nest / eggs, rockets, bridge vehicles, cats etc. only after the core direction is clearer.

### Material language

Readable Young/Wet/Frozen/Glued/Burnt states remain promising, but invest deeply only if the final game still benefits from those states after function-first testing.
