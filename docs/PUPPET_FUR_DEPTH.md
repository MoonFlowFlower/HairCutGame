## 原因与改动

上一轮压制闪光时，毛片明暗主要跟随大轮廓平均法线，没有表达前后毛束的遮光，所以细毛很多，整体仍像一片平绒。参考的层次需要毛簇亮面、沟槽和散尖之间的差别。

这轮给体积采样和原始曲线 fins 加上同一种局部遮挡近似：沿固定主光方向，在原材料坐标的 3/9/18/35mm 处查询经过滤的毛束覆盖；用**当前**占据门控遮挡，再由累计覆盖衰减直接光。剪掉的材料不会继续贡献遮挡。保留环境光下限，调整原曲线根尖明暗；不使用黑色轮廓边或新切面的噪声贴皮。

最终 C 将遮挡的过滤范围放宽至毛簇尺度，并用实际屏幕像素足迹限制最细级别；经度导数仍处理周期接缝。细毛形状、八层采样、原根、828,520 个 fin 三角形、alpha 覆盖、裁剪规则、回弹参数均不改。`PuppetFurMotion.cs` 保持 Owner 已认可版本的 SHA256 `B819D52DBB4FD33312C23B0EBEA59164F9D599C280763C1F841CF117D57F3032`。

这是四个探针的风格化近似，采样静息材料中的覆盖与剪后占据；不是完整的变形毛发光传输，也不接收所有场景灯的阴影。毛发向身体/环境的实际投影仍未补齐。HairVolume 始终是占据，未当作 SDF；原作者公式仍未取得，不宣称复刻其源码。

## 动态与回归

depth B 的三态原生剪切共 590 帧用于初版评审；**不将它们算作最终 C 的录像**。最终 C 另外录制 Carved 原生六次 LMB 剪切：182 帧、7.503s 实时、450 物理帧/7.500s；固定第一人称镜头与头部，没有风/接触注入。原根场和 fin mesh 保留、剪后 density 不回生、空剪不发冲量，最后导向点残差低于0.5mm。

最终 C 的182帧在剪前/后共同存活毛发 mask 的侵蚀 ROI 内，没有检测到 RGB 全通道 >245 的爆亮像素；ROI 外及未采样运动没有被此结论覆盖。[实际 Carved 连剪录像](D:/Project/Game/Godot/project_hairball/artifacts/puppet-fur-depth/final-c/cut-carved/motion-verified.mp4)。另外保存最终 C 的161帧相机采样、同构建关闭新遮挡的156帧采样；这些是相机运动，不是受力物理证据。三条最终 MP4 逐帧核对时间戳，误差≤0.5ms、没有插帧。

同一侵蚀 Core ROI，0.15–0.75s 静止段的相邻帧 RGB 平均绝对差：本轮前明暗0.210/P99=2，最终C为0.368/P99=3（8-bit，16/17帧）。初版B为0.487/P99=4，C有所收敛，**但仍比本轮前更容易显出细小跳动**。亮度/对比度与采样间隔不同，不能将这个值当作抗锯齿单一变量证明或通用摩尔纹评分。中尺度对比和视觉层次改善，不解除闪烁验收。

本轮 C# 编译通过，Core 248/248。最终 C 在实际 Godot 中再次完成体积检查 34 + 空头检查 9，包括 108 次真实 LMB 剪空、重置、再剪；没有空网格错误。4/8/12/16 的检查是权威/几何不变性检查，不是新增层数的美术放行。正式 B/R6 与网络/工具权威不变，没有重跑或声称整个 B/WAN 回归通过。
