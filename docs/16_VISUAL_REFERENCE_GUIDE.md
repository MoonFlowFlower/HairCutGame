# 16 — Visual Reference Guide v0.3

The images in `docs/reference/` are approved visual-intent references, not pixel-perfect UI/art requirements.

## 01_shared_head_first_person_helipad.png
Primary reference for:
- first-person shared-head gameplay,
- one customer filling the center,
- several players visibly acting on the same head,
- chunky hair pieces,
- different tools overlapping in one work zone,
- panic/comedy readability,
- simple goal/timer HUD concept.

Ignore exact names, text, colors, UI layout, and tool models.

## 02_shared_head_first_person_llama_nest.png
Reference for:
- non-human customers,
- head material other than ordinary human hair (wool),
- one special customer behavior (spit),
- four-player crowding around one chair,
- goal prop staging (eggs),
- first-person own-tool readability.

Do not interpret the image as requiring all shown content in the first migration milestone.

## 03_shared_head_salon_layout.png
Primary spatial reference:
- one central chair,
- 360-degree access,
- four informal approach zones without hard player ownership,
- tools around perimeter,
- validation props staged nearby,
- mirrors and enough room for physical accidents.

Colored floor lanes are concept communication only; do not lock players to lanes unless useful for debugging.

## 04_customer_archetypes.png
Reference for content direction:
- human, llama, chicken, alien variety,
- each customer has one readable signature behavior,
- player barber hair also gets ruined,
- head materials can vary while preserving a shared interaction family.

This is future-facing; baseline acceptance only needs the human customer.

## 05_hair_system_states.png
Reference for material readability:
- normal,
- overgrown,
- frozen/rigid,
- charred,
- glued,
- punctured.

The exact infographic/text is not in-game UI.

## Visual priority order
1. Causal readability.
2. Customer/head readability.
3. Tool-to-material feedback.
4. Teammate body/tool awareness.
5. Funny physical consequence.
6. Low-poly coherence.
7. Decorative polish.
