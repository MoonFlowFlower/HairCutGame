# 06 — Tool Interaction Spec v0.3

## Core rule

A tool is valuable when its rule has legitimate uses and collateral consequences.

Do not make absurd tools mere weapons. The player should pick them because they solve the head problem faster or differently.

## Required prototype tools

### 1. Clippers
Rule: precise local removal.
- safe,
- controllable,
- slower than dangerous alternatives.

### 2. Growth Spray
Rule: cone/stream adds head material.
- fills missing areas,
- builds height/volume,
- can overshoot,
- airborne spray can be redirected by strong wind,
- can affect player hair.

### 3. Leaf Blower
Rule: directional force field.
Affects where reasonable:
- flexible head material,
- detached bundles/wigs,
- light props,
- airborne spray/smoke/flame direction,
- player bodies at close range.

### 4. Vacuum Transfer Cannon
Primary: suck compatible material/debris into storage.
Secondary: eject stored material.
- reshape/remove,
- move material between areas,
- steal material from player hair,
- tug a player if their long hair remains attached.

### 5. Glue Gun
Rule: create attachment/fixed-shape relationships.
- fuse material chunks,
- anchor material to props/world when valid,
- hold structures together,
- mistakes become difficult to correct.

### 6. Hedge Trimmer
Rule: broad moving cutting volume/plane.
- excellent for helipad/flat surfaces,
- tool has real spatial extent,
- turning with it can hit things/players/material unintentionally.

## High-priority additions

### 7. Sniper / Precision Puncture Tool
- narrow precise removal/puncture,
- line of fire continues,
- customer motion can make the shot miss,
- limited ammunition.

### 8. Flamethrower
- high-speed area removal through heat/fire,
- can ignite material/props,
- airflow can redirect fire behavior,
- very useful and obviously risky.

## Later commitment tool

### Bald Bomb
Once armed, cannot be cancelled. After short countdown, removes compatible head material in radius.

Purpose:
- introduces "I already started this and now must deal with it" comedy,
- should be powerful enough to tempt use.

## Interaction matrix examples

- blower + growth spray -> spray drifts across head/room,
- blower + fire -> changes flame direction/spread,
- glue + blower -> glued section holds while flexible section moves,
- vacuum + player hair -> body tug,
- water/wet + fire -> reduced ignition,
- freeze + impact -> brittle break,
- customer duck + sniper -> missed line of fire,
- hedge trimmer + customer recoil -> unintended cut path.
