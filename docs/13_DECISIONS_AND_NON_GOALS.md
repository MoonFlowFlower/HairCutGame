# 13 — Locked Decisions & Non-Goals v0.3

## Locked decisions

### Core mode
- 1–4 players share ONE active customer/head.
- Shared cooperative objective and shared payout.
- Main comedy is accidental interference and rescue, not intentional PvP.

### Perspective
- First-person 3D.
- Third-person allowed only for replay/spectator.

### Controls
- FPS-simple.
- Physical pickup/drop.
- One main held tool.
- No primary hotbar/tool wheel.

### Round
- Short group vote among 3 goals.
- 75s default build time.
- No individual early submit/cash-out in the shared-head main mode.
- Validator may enter the scene before timer reaches zero.

### Customer
- living/semi-cooperative,
- hidden panic,
- small causal reactions,
- anticipation cues,
- reactions should create accidents but not constant frustration.

### Scoring
- one shared job result/shop-money delta,
- individual awards are comic attribution only.

### Hair/material
- chunky low-poly deformable interaction system,
- interaction > realism,
- player hair can also be affected,
- architecture should not permanently assume only human hair.

### Tools
- broad physical rules,
- useful and dangerous,
- collisions/effects may affect players, props, customer, and material.

### Networking
- Godot 4.7.2 .NET C#,
- host authoritative,
- ENet prototype,
- game facts synchronized, cosmetic motion mostly local.

## Explicit non-goals for the current core migration
- four independent player customers,
- individual score race,
- fixed salon professions,
- mandatory wash/cut/dry workflow,
- deep management/economy,
- ranked PvP,
- realistic hair,
- complex animal/monster AI,
- realistic gore/injury,
- Steam integration,
- matchmaking/dedicated servers,
- final art.

## Deferred questions for playtest evidence
- exact ideal round time,
- whether group goal vote should allow veto/leader tie-break later,
- exact panic frequency/intensity,
- whether brief customer stand/run behavior improves comedy,
- how harsh injury/property penalties should be,
- which special customer should be second after human,
- whether commitment tools belong in the first public demo.
