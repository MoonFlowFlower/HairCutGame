# 38 — v0.6 Visual Reference Guide

These images communicate interaction intent. They are not asset/UI specifications.

## 01 — Live helipad landing

`reference_v06/01_live_helipad_landing_ad_reference.png`

Read this image as:

- customer is alive and looking toward the approaching helicopter;
- one teammate is bracing the head;
- another is still modifying the platform;
- helicopter is physically descending while work continues;
- reference material is an ad/fantasy of the outcome, not a technical blueprint.

Ignore invented branding, player names, exact UI layout, costume details and exact tool appearance.

## 02 — Mirror cover-up

`reference_v06/02_customer_mirror_coverup_reference.png`

Read this image as:

- something has gone wrong behind the customer;
- a teammate physically blocks mirror visibility;
- another teammate repairs the problem;
- customer begins to notice (`?`) but has not yet committed to the reaction;
- “hiding the evidence” is a physical/visibility action, not a scripted minigame.

## 03 — Directional attention

`reference_v06/03_directional_attention_telegraph_reference.png`

Read this image as:

- one teammate deliberately creates a sound/attention source;
- customer turns toward a source with readable warning;
- another teammate uses the resulting access window;
- attention can be manipulated and has direction.

The tutorial-like overlays are explanatory art only. Do not ship them as-is.

## 04 — Physical mission props (future/reference)

`reference_v06/04_physical_bird_nest_props_future_reference.png`

This is not a required v0.6 B mission.

It preserves a future rule already approved by product direction:

- eggs / props exist during construction;
- players physically place them;
- they can fall, roll, blow away or be mishandled;
- validation tests the same objects rather than spawning replacements into success positions.
